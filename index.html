Defib

Autonomous Quorum Rescue Agent for DAOs

Monitors governance proposals, evaluates quorum risk on-chain, triggers targeted voting incentives, and emits auditable Proof of Reasoning receipts.

Run the demo Architecture

The problem

DAO proposals often fail quorum due to apathy and coordination delays near deadlines, not because of active opposition. By the time humans react, it’s too late.

The solution

Defib continuously monitors proposal state, computes a risk score, deposits incentives when proposals are critically at risk, and records a receipt for auditability.

What’s on-chain

  • DefibCore.sol — risk math + proof receipts
  • BountyVault.sol — holds/dispenses incentives
  • MockDAO.sol — governance simulation harness
  • MockToken.sol — incentive token (DFIB)

Architecture

Quickstart

Install deps and run the end-to-end demo:

npm install --legacy-peer-deps
npx hardhat run scripts/demo.ts

Run tests:

npx hardhat test
